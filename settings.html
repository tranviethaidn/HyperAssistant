About HyperAssistant

HyperAssistant is a powerful Chrome extension designed to help you translate content across multiple languages with ease. Whether you're translating selected text on a webpage or inputting custom text, HyperAssistant delivers fast and accurate results.

Powered by Google's Gemini API from Google AI Studio, it offers advanced translation capabilities with customizable model options to suit your needs. With its high speed, precision, and flexibility — all completely free — HyperAssistant is the ideal tool for seamless communication in any language.

How to Use

1. Basic Setup

A. Pin the Extension

Click the Chrome extensions icon... ...

B. API Settings

Get your personal API key from Google AI Studio:

  • Visit: Google AI Studio.
  • Create new API key.
  • Add your API key to the input field.
  • Then click the "Save Settings" button.
